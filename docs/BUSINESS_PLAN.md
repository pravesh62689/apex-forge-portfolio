# AGENCY SCALING ROADMAP

## Pricing Model & Delivery
*   **Starter (₹6,000 - ₹8,000):** One-page Next.js template. Hero, Services, Gallery, Contact, WhatsApp CTA. Hosted on Cloudflare Pages (Free). Delivery: 24 hours. Margin: 95%.
*   **Standard (₹12,000 - ₹15,000):** Multi-section, CMS integration (Sanity/Supabase free tier) for menu/services updates. Basic On-page SEO. Delivery: 48 hours.
*   **Premium (₹20,000 - ₹30,000+):** Full SEO package (Local Citations, Schema Markup), Lead capture form to Google Sheets, Custom animations. Maintenance plan upsell (₹2,000/mo).

## Step-by-Step Execution Plan

### Day 1-3: The Foundation
- Deploy the Next.js Portfolio site with the 10X architecture.
- Build 3 hyper-polished demo sites using the `template-factory.ts` (1 Salon, 1 Dentist, 1 Gym).
- Set up the Google Sheet CRM.

### Week 1: Lead Generation & Outreach
- Run local searches: "PG in Sector 104 Noida", "Dentist in Sector 18 Noida".
- Find 50 businesses with NO website but good reviews.
- Send the WhatsApp "Soft Pitch" script to all 50.
- Goal: Secure 3 demo presentations.

### Month 1: The First ₹20K
- Target: Close 3 Starter websites at ₹7,000 each = ₹21,000.
- Fulfillment: Use the predefined Next.js templates. Host on Vercel/Cloudflare.
- Action: Collect video testimonials from these first 3 clients.

### Month 3: Hitting ₹50K
- Target: 3 Standard (₹12K) + 2 Starter (₹7K) = ₹50,000.
- Introduce the SEO upsell: Offer to optimize their Google Business Profile and add Schema markup to the site for an extra ₹3,000.
- Automate lead scraping using local n8n workflows.

### Month 6 to 12: Scaling to ₹1 Lakh - ₹3 Lakh
- Shift focus from Starter to Premium packages.
- Target: 5 Premium (₹20K) = ₹1 Lakh.
- Build recurring revenue: 20 clients on ₹2,000/month maintenance/hosting retainers = ₹40,000/mo passive baseline.
- Outsource: Hire a junior developer/intern to handle the template deployment and content entry while you focus entirely on sales and strategy.
